This repository contains some basic code for correction solar rotation in radio interferometric images.
The code named "combine_rotated_ms_uv_plane.py" does all the correction. The code has many hard-coded
parameters, and the user should understand those before running the code. Some other codes for testing
the algorithms designed for correction of simple image plane transformations during deconvolution are
also provided. Again the idea is to provide the user with some guidance so that they can implement their
own test codes.
